# 消费者评估量表 1.1

五个维度固定等权，每项只取 0、1、2 分。先记录海报证据，再选择锚点；不要用整体印象补偿缺失信息。

| 分数 | 统一含义 |
|---:|---|
| 0 | 缺失、明显冲突、无法理解或造成误解 |
| 1 | 有表达，但不够突出、完整或有说服力 |
| 2 | 清楚、完整，能够支持目标消费者判断 |

## 商品与品牌识别 `product_recognition`

- 0：无法识别商品，或商品主体与原始商品图明显冲突。
- 1：商品可识别，但主体、品牌或品类关系不够明确。
- 2：消费者能快速、正确识别商品主体及相关品牌信息。

## 消费利益与卖点传达 `benefit_clarity`

- 0：核心卖点缺失、错误，或出现未经输入支持的功效。
- 1：卖点出现，但没有形成与主购买动机相关的明确利益或证据。
- 2：核心卖点清楚、可信，并能回答目标消费者为什么需要它。

M 动机决定什么算有效利益，但不改变本维度权重。

## 价格促销与活动信息 `offer_visibility`

- 0：价格错误，或营销目标明确要求的关键促销信息缺失。
- 1：信息存在但不易发现、条件不完整或理解成本较高。
- 2：价格及输入中明确要求的促销信息清楚、准确、易读。

若 `price_text` 为空且 `marketing_target` 也未要求价格，不因价格缺失扣分；按其他明确交易信息判断。

## 人群与场景适配 `population_scene_fit`

- 0：表达与锁定 P 人群或 S 场景明显冲突。
- 1：存在相关线索，但商品与人群生活或使用场景的联系较弱。
- 2：目标消费者能明确感到与自己有关，并理解商品在指定场景中的用途。

这里检查锁定标签是否被有效传达，不重新进行分类。

## 购买信心与行动驱动 `purchase_drive`

- 0：信息引发明显不信任、误解或拒绝。
- 1：愿意继续了解，但购买理由、可信度或行动提示不足。
- 2：购买理由可信，消费者理解为什么买以及为什么现在行动。

## 汇总与通过

```text
score = product_recognition
      + benefit_clarity
      + offer_visibility
      + population_scene_fit
      + purchase_drive
```

`score` 为 0–10 的整数。`score >= 7` 且不存在关键问题时 `pass = true`。关键问题不能被其他维度高分抵消。

同一观察只选择一个主要归属维度。只有存在第二个独立消费者后果时，才允许另一维度同时扣分。
